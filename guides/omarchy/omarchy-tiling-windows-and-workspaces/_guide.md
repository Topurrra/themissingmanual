# Omarchy Tiling Windows and Workspaces

On Windows and macOS you spend a surprising amount of time managing windows: dragging them, resizing them, hunting for the one buried under three others. Omarchy removes that work. Windows share the screen and never overlap, so the job shifts from arranging to steering.

This guide builds the mental model, then the keys: how windows split space, how you focus, move, swap, and resize them, the modes that take a window out of the normal flow, and how workspaces and monitors extend it all. Checked against Omarchy 4.0.4.

## Prerequisite

You should have Omarchy running and know that `Super + Space` opens the menu. If the key notation or the missing dock is new, read [Omarchy for Windows, macOS, and Ubuntu Users](/guides/omarchy-for-windows-macos-and-ubuntu-users) first.

## How to read this

- **In a hurry?** Do the three-window exercise in Phase 1 and the workspace drill in Phase 4.
- **Want it to stick?** Read in order, with Omarchy open beside you. Every key is meant to be pressed.
