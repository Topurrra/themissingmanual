# Installing Omarchy

The scary part of installing an operating system is not the typing. It is the moment a progress bar starts and you realize you are not sure what it is about to erase. This guide takes that uncertainty away: you will know before you start what gets wiped, what the installer asks, and what to check once it finishes. Checked against Omarchy 4.0.4.

## Prerequisite

You do not need Linux experience. If you are still deciding whether Omarchy is for you, read [What Omarchy Actually Is](/guides/what-omarchy-actually-is) first. It also helps to know roughly what the firmware and bootloader do, which [How Your Computer Boots](/guides/how-your-computer-boots) explains.

## How to read this

- **Installing to a whole drive?** Read Phases 1, 2, and 4.
- **Keeping Windows?** Read Phase 1, then Phase 3 before you touch the Windows partition.
- **On an Intel Mac?** Phase 3 has the Mac steps.
- **Want it to finally make sense?** Read in order.

## The phases

1. **[Before You Install](01-before-you-install.md)** - backups, hardware reality, the firmware switches, and making the USB stick.
2. **[The Install Walkthrough](02-the-install-walkthrough.md)** - booting the stick and what each question asks.
3. **[Dual Boot and Special Installs](03-dual-boot-and-special-installs.md)** - keeping Windows, Intel Macs, installing for someone else, and "Omarchy on..." options.
4. **[Your First Boot Checklist](04-your-first-boot-checklist.md)** - network, updates, displays, and where to learn next.

After this: [Omarchy for Windows, macOS, and Ubuntu Users](/guides/omarchy-for-windows-macos-and-ubuntu-users) turns your old habits into Omarchy ones.
