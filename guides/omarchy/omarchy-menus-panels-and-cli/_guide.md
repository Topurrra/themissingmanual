# Omarchy Menus, Panels, and the CLI

On Windows you open Settings. On macOS you open System Settings. On Omarchy there is no Settings app, and that is the first thing that makes people feel lost. The settings did not vanish. They moved into three places that all do the same job in different ways: a keyboard-driven menu, a top bar with popup panels, and a command called `omarchy`.

This guide gives you a map of all three. By the end you will know which door to use for which job, how to flip modes like do not disturb and night light, and how to read what the `omarchy` command offers without memorizing it.

Checked against Omarchy 4.0.4.

## Prerequisite

You need a running Omarchy install. If you are not there yet, start with [Installing Omarchy](/guides/installing-omarchy). If a terminal still feels foreign, [The Terminal and Shell](/guides/the-terminal-and-shell) is the friendly on-ramp.

## How to read this

- **In a hurry?** Read Phase 1 for the menu, then skim the hotkey tables in Phase 2.
- **Want it to finally make sense?** Read in order. The menu, the bar, and the command are three views of the same system, so each phase explains the next.
- **Coming from another OS?** [Omarchy for Windows, macOS, and Ubuntu Users](/guides/omarchy-for-windows-macos-and-ubuntu-users) translates your old reflexes first.
